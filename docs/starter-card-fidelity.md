# Starter card fidelity

The source is `tem/六界之峰.xlsx`. Row numbers refer to the named worksheet. Review each printed clause, then apply the recorded project rulings where the workbook wording has been clarified. Links point to assertions against real definitions unless the entry calls out a shared rule or fixture. A registered definition or a passing fixture alone does not settle every printed clause.

## Scope

The printed category, color, and base cost agree with all 136 registered starter definitions under the current energy mappings. This includes all 78 creature attack and life values and all eight equipment attack bonuses. For equipment, the workbook’s attack column is a bonus to the equipped creature.
